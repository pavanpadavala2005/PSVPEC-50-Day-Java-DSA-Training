## 📖 About This Training

This repository contains the **complete course material delivered during a 50-Day Campus Recruitment Training (CRT) program at PSVPEC, Chennai**.

The training was designed to help students build a strong foundation in **Java, Problem Solving, Data Structures & Algorithms, SQL, and Computer Science fundamentals**, with an emphasis on **placement-oriented coding and logical thinking**.

The repository contains the resources used throughout the training, including:

    -> ☕ Java programming concepts & programs
    -> 🧠 Problem-solving exercises
    -> 📚 Data Structures & Algorithms
    -> 🔁 Recursion
    -> 🔤 String problem solving
    -> 📦 Stacks & Queues
    -> 🗄️ SQL & database practice
    -> 💻 Classroom coding programs
    -> 📝 Practice questions
    -> 📄 Notes & reference PDFs
    -> 🔄 Study material

---

## 🎯 Training Objective

The primary objective of this training was to help students move from:

```text
                                    Programming Fundamentals
                                              ↓
                                      Java Programming
                                              ↓
                                    Logical Problem Solving
                                              ↓
                                       Data Structures
                                              ↓
                                          Algorithms
                                              ↓
                                      SQL & CS Fundamentals
                                              ↓
                                 Placement-Oriented Problem Solving
```

The focus was not only on learning syntax, but on developing the ability to:

> **Understand → Analyze → Implement → Debug → Optimize**

# 📥 How Students Can Get These Resources

## You can get the complete training material directly from GitHub.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/pavanpadavala2005/PSVPEC-50-Day-Java-DSA-Training.git
```

### 2️⃣ Enter the repository

```bash
cd PSVPEC-50-Day-Java-DSA-Training
```

### 3️⃣ Get the latest updates

If you already cloned the repository:

```bash
git pull origin main
```

That's it! 🎉

You now have the complete training resources available locally.
